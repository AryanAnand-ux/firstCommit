Source: <https://www.wemakedevs.org/aws/first-commit/rules> (tour rulebook).

- University student in India, 18+. Each member must qualify on their own.
- Required: WeMakeDevs account + **AWS Builder Center profile with verified university enrollment** (SheerID).
- ⚠️ **ACTION:** verify enrollment today via <https://bit.ly/abc-verify> — it unlocks $579 of rewards and is required for prizes. If SheerID is still processing, enter anyway (doesn't block submission).

## 2. Teams

- 1–4 people; captain does NOT register others — **every member registers with their own account**.
- One submission per team.

## 3. What we build (compliance checklist)

- [x] Start building when the hackathon opens (**Sept 17**), stop at the deadline (**Sept 20**).
- [x] **Repo history must fall inside event dates.** First commit is dated within Sept 17–20. Do not push pre-written work. (We scaffolded inside the window.)

- [x] Demo video must show AWS (architecture slide + live console/URL shots).
- [x] AI tools used must be listed in the writeup → OpenCode CLI (opencode/big-pickle model) for scaffolding + coding assistance.
- [ ] **Public repo** — set repository visibility to public BEFORE submitting.
- [ ] Free tier: new AWS account = up to $200 credits. Request more via <https://forms.gle/v1fMc8YboFvERz8j6> if needed.

## 4. Submission (3 parts)

1. **Public GitHub repository** (this one) — history inside event dates.
2. **Demo video**: YouTube, <3 min, public or unlisted, plays in a signed-out browser. Must show: what it does / who it's for / where AWS fits.
3. **Writeup**: problem / build / where AWS fits. → `WRITEUP.md` template.

Submit once per team before the deadline on the submission form. **No live demo — the video is all judges see.**

## 5. Judging criteria (what to nail)

| Criterion | Weight note | Our play |
|---|---|---|
| Idea & Impact | Real problem + what changes | Blood scarcity: minutes vs hours, SMS + AI |
| Built on AWS | Mandatory | 9 AWS services, 3 tracks deep |
| Learning | Say what we learned | README "What we learned" + writeup section |
| Execution | One thing that WORKS | End-to-end request→match→confirm, tested |
| Demo video | 3 min | `DEMO_SCRIPT.md` beat sheet |

Judges: AWS Solution Architects & TAMs — they will read the architecture and the security posture. `architecture.md` is our proof.
